# Security Policy

## Reporting a vulnerability

Do not open a public issue. Report privately to **maximilienwhite7@gmail.com** with:

- the affected repository,
- steps to reproduce,
- the impact you believe it has.

You will receive an acknowledgement, and a fix or an explanation.

## Automated protection

All repositories in this organization run:

- **Secret scanning** and **push protection** — blocks credentials before they land.
- **Dependabot** alerts and security updates.
- **CodeQL** analysis on a weekly schedule.

New repositories inherit these settings automatically.
